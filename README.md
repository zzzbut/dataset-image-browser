# 图片筛选工具 (Image Browser)

一款基于 Tkinter 的轻量级图片浏览与数据集筛选工具，支持图片预览、缩放拖动、YOLO 标签可视化、分类标记、批量复制/移动、视频抽帧（decord 引擎）、相似图片去重（CPU pHash + 颜色直方图）等功能。

> 当前版本：**v1.0.20**（CPU-only）
> 自 v1.0.20 起已完全移除 GPU/CUDA/torch 依赖，去重改为纯 CPU 的 pHash + 颜色直方图，视频抽帧统一使用 decord 引擎，并精简了打包体积。

## 功能特性

### 核心功能

#### 1. 数据浏览
| 功能 | 说明 |
|------|------|
| 图片预览 | 支持 jpg、jpeg、png、bmp、webp 等格式，可打开目录浏览 |
| 缩放拖动 | 鼠标滚轮缩放（以鼠标为中心），左键拖拽平移 |
| 上下张切换 | 工具栏按钮或键盘方向键切换 |
| 递归子目录 | 可选是否读取子目录中的图片 |
| 快速定位 | 状态栏滑块拖动定位，输入数字跳转到指定位置 |
| 进度保存 | 关闭后重新打开自动恢复到上次浏览位置 |

#### 2. 标签显示与编辑
| 功能 | 说明 |
|------|------|
| YOLO 标签可视化 | 支持 detect / obb / segment / pose 四种标签绘制 |
| 类别过滤 | 可勾选显示/隐藏特定类别的标签，列表超 6 项自动出现滚动条 |
| 标签同步操作 | 图片复制/移动时自动同步同名标签文件 |
| 标签格式支持 | YOLO 格式（.txt），每行包含 class_id 和边界框/关键点坐标 |
| 匹配图片列表 | 标签目录下匹配到标签的图片以列表形式展示（含滚动条、当前行高亮） |
| classes 文件历史 | 上传过的 classes 文件路径会被记住，下次可从下拉框快速选择 |
| 路径友好显示 | 标签目录、classes 文件、COCO JSON、转移目录等长路径自动缩短，鼠标悬停显示完整路径 |

#### 3. 标记转移
| 功能 | 说明 |
|------|------|
| 分类标记 | 可添加多个分类（如「合格」「不合格」「漏检」「误检」），点击标记 |
| 横向按钮布局 | 标记分类按钮左右排布，节省纵向空间 |
| 批量标记 | 支持批量操作，对选中图片进行标记 |
| 标记文件 | 标记后在图片所在目录生成对应的 txt 文件 |
| 一键转移 | 「批量转移」按钮自动选择目标目录并执行转移；「更改目录」可单独指定 |
| 标签同步 | 图片复制/移动时自动同步处理标签文件 |

#### 4. 视频抽帧
| 功能 | 说明 |
|------|------|
| 抽帧引擎 | 统一使用 **decord** 引擎，批量解码（按 chunk_size），批量失败自动回退逐帧解码 |
| 视频选择 | 支持选择视频文件夹，批量处理 |
| 抽帧间隔 | 可设置按时间间隔（秒）或按帧数间隔抽帧 |
| 灰图过滤 | 自动检测并跳过灰帧（gray_thresh 可调） |
| 相似帧过滤 | 自动过滤相邻相似帧（sim_thresh 可调） |
| 输出组织 | 支持平铺（所有图片放输出根目录，以视频名为前缀）或按视频子文件夹组织（flat_save 参数） |
| 输出格式 | 支持 PNG 输出，可配置压缩级别 |
| 进度显示 | 实时显示处理进度和已处理视频数 |

#### 5. 相似去重
| 功能 | 说明 |
|------|------|
| 算法模式 | 纯 CPU 模式：pHash + 颜色直方图（无需 GPU） |
| 参数调节 | pHash 距离阈值 + 颜色相似度阈值 |
| 智能聚类 | 自动将相似图片分组，支持查看和管理 |
| 缩略图缓存 | 加速大量图片的相似度结果显示 |

## 界面预览

程序采用多面板 Tab 式设计，主要包含：
- **数据浏览** - 图片浏览和基本操作
- **标签显示** - YOLO 标签可视化配置
- **标记转移** - 分类标记和批量操作
- **视频抽帧** - 视频转图片提取
- **相似去重** - 重复图片检测和清理

## 安装与运行

### 环境要求
- Python 3.8+
- Windows 10/11
- 无需 GPU，纯 CPU 运行

### 依赖安装

```bash
# 创建 conda 环境（推荐）
conda create -n image_browser python=3.10
conda activate image_browser

# 安装核心依赖（见 requirements.txt）
pip install -r requirements.txt
```

`requirements.txt` 内容：

```
Pillow>=10.0
opencv-python-headless>=4.8
appdirs>=1.4.4
decord>=0.6
```

> numpy 作为 opencv / decord 的依赖会被自动安装。

### 运行程序

```bash
# 进入项目目录
cd image_browser

# 直接运行
python main.py
```

## 打包为 exe

### 环境要求
- Python 3.8+
- Windows 10/11
- PyInstaller: `pip install pyinstaller`

### 打包（CPU-only）

```bash
# 安装 PyInstaller
pip install pyinstaller

# 进入项目目录
cd image_browser

# 运行打包脚本（默认 onefile + 窗口模式）
python build.py

# 可选参数
python build.py --console      # 保留控制台窗口（调试用）
python build.py --onedir       # 打包为文件夹而非单文件
```

输出文件：`dist/ImageBrowser.exe`

`build.py` 已针对体积做精简，排除未使用的标准库（asyncio、email、http、urllib、xml 等）、第三方库（matplotlib、scipy、pandas、PyQt5/6 等）、tkinter 子模块以及大部分 PIL 图像格式插件（仅保留 jpg/png/bmp/webp/tif）。

### 注意事项

#### 文件体积
- **CPU 版本**：体积较小，依赖少，适合所有用户

#### 常见问题

**Q: 打包失败怎么办？**
A:
- 检查 PyInstaller 是否正确安装：`pip show pyinstaller`
- 清理缓存后重试：`rmdir /s /q build dist 2>nul & python build.py`
- 查看详细错误信息

## 使用说明

### 1. 数据浏览
1. 点击「打开图片目录」选择包含图片的文件夹
2. 使用工具栏按钮或键盘方向键切换图片
3. 滚动鼠标滚轮缩放，按住左键拖拽平移
4. 拖动底部滑块或输入数字快速定位

### 2. YOLO 标签可视化
1. 切换到「标签显示」面板
2. 点击「选择标签文件夹」选择包含 `.txt` 标签文件的目录
3. 点击「选择 classes 文件」加载类别映射文件（可选）
   - 若没有 classes 文件，可选择「是」按 class_id 递增自动命名
   - 选择「否」则从文件导入 classes 文件，导入后路径会记入历史，下次可从下拉框快速选择
4. 在下拉框中选择标签类型：**detect**、**obb**、**segment**、**pose**
5. 勾选「显示标签」或按 `T` 键切换标签显示
6. 在「类别过滤」中勾选需要显示的类别
7. 匹配到的图片会显示在图片列表中，当前图片所在行高亮，可用滚动条浏览

### 3. 分类标记
1. 切换到「标记转移」面板
2. 在「标记分类」区域添加分类（如「合格」「漏检」「误检」）
3. 点击分类按钮对当前图片进行标记（按钮左右排布）
4. 点击「批量转移」一键选择目标目录并转移已标记图片；或先点「更改目录」指定目录后再转移
5. 图片复制/移动时会自动同步处理同名 `.txt` 标签文件

### 4. 视频抽帧
1. 切换到「视频抽帧」面板
2. 点击「视频文件夹」选择包含视频的目录
3. 点击「输出文件夹」选择抽帧图片的输出目录
4. 设置抽帧间隔（秒或帧数）
5. 可选：开启/关闭平铺保存（flat_save）、灰图过滤阈值、相似帧过滤阈值
6. 点击「开始抽帧」启动处理（使用 decord 引擎，支持多视频任务）

### 5. 相似去重
1. 切换到「相似去重」面板
2. 点击「图片文件夹」选择需要检测的目录
3. 设置相似度参数：
   - **pHash 距离**（0-64）：越小越严格
   - **颜色相似度**（0-1）：越大越宽松
4. 点击「扫描」开始检测（纯 CPU）
5. 扫描完成后点击「查看」浏览相似图片组
6. 选择需要删除的重复图片，点击「转移」进行清理

## 算法说明

### 相似去重（CPU pHash + 颜色直方图）
- **pHash**：感知哈希算法，通过比较图像的哈希值判断相似度
  - pHash 距离越小，表示图片越相似
  - 距离 ≤ 2：直接判定为相似
  - 距离在阈值内：结合颜色直方图综合判断
- **颜色相似度**：通过比较颜色直方图判断颜色相似程度
  - 值越大，表示颜色越相似（找出更多相似图片）

## 配置说明

配置文件位于 `~/.image_browser/config.json`，包含：
- 上次浏览目录和进度
- 分类标记列表
- 相似去重任务配置
- classes 文件历史记录
- 性能模式设置

标记数据存储在图片所在目录的 txt 文件中（如「合格.txt」），每行一个绝对路径。

## 常见问题

**Q: 标记文件在哪里？**
A: 在图片所在目录下，文件名为分类名称（如「合格.txt」）。

**Q: 相似去重的参数如何调节？**
A: pHash 距离越小越严格，颜色相似度越大越宽松；颜色相似度越大，找出的相似图片越多。

**Q: 批量操作时标签会同步吗？**
A: 会。图片复制/移动时会自动查找并同步处理同名 `.txt` 标签文件。

**Q: 撤销能恢复被移动的文件吗？**
A: 可以，撤销会将文件移回原目录。

**Q: 需要安装 GPU 驱动或 CUDA 吗？**
A: 不需要。v1.0.20 已移除全部 GPU/CUDA/torch 依赖，相似去重与视频抽帧均纯 CPU 运行。
